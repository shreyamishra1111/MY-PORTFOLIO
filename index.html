Student Performance Dashboard A C programming project designed to manage student records, calculate academic performance, and display results through a simple dashboard.
Problem
Managing student records and calculating academic performance manually can be time-consuming and prone to errors. Students' marks, percentages, grades, and pass/fail status need to be organised systematically for easy performance tracking and analysis.
Goal
Develop a C-based student performance management system that stores student details and marks, calculates total marks and percentages, assigns grades, identifies pass/fail status, and displays student performance in an organised format.
My Contribution
Developed this project individually as part of my C Programming PBL. I worked on analysing the problem, designing the program logic, writing and debugging the C code, and implementing features to manage student records and evaluate academic performance. I also worked on calculating totals, percentages, grades, and pass/fail results.
Tools and Technologies
  1. C Programming Language – Core programming and implementation.
  2. C Compiler / IDE – Writing, compiling, and executing the program.
  3. MS Word / Google Docs – Project documentation and report preparation.
Process
  1. Identified the problem of manually managing student records and calculating academic results.
  2. Analysed the requirements and planned the program structure.
  3. Used variables, arrays, strings, loops, and conditional statements to manage student information.
  4. Implemented features to store student details and subject-wise marks.
  5. Calculated total marks and percentages for each student.
  6. Implemented grade allocation and pass/fail evaluation.
  7. Tested the program using sample student records and verified the output.
Evidence
  • C program source code.
  • Flowchart and algorithm documentation.
  • Program execution screenshots.
  • Sample output showing student details, marks, percentages, and grades.
  • Project report and documentation.
Learning
Through this project, I strengthened my understanding of C programming concepts, including arrays, loops, conditional statements, and strings. I gained practical experience in problem-solving, algorithm design, debugging, and handling student data. Working individually also improved my independent development, logical thinking, and programming skills.
Smart Cybersecurity Awareness A project focused on improving public Wi-Fi security awareness by educating users about fake hotspots, online threats, and safe network practices.
Problem
People often join a public network simply because the name looks right. Fake hotspots, Evil Twin attacks, and Man-in-the-Middle risks are real, but existing warnings are often too technical, too generic, or shown before users need to make a decision.
Goal
Help users judge a network quickly, identify duplicate-name or suspicious hotspots, understand risks through a simple colour rating, receive warnings before banking, UPI or login activities, and build safer online habits through short, repeated tips.
My Contribution
As the Problem Statement Lead, I was responsible for identifying and analysing cybersecurity awareness challenges faced by people while using public Wi-Fi networks. I researched common threats such as fake Wi-Fi hotspots, Evil Twin attacks, and Man-in-the-Middle attacks. I contributed to defining the problem, identifying the target audience, understanding security risks, and suggesting practical ways to improve users' cybersecurity awareness.
Tools and Technologies
  1. Canva – Report and presentation design.
  2. Internet Research – Studying cybersecurity threats and safety practices.
  3. MS Word / Google Docs – Documentation and report preparation.
Process
  1. Identified the problem of low cybersecurity awareness among public Wi-Fi users.
  2. Researched common threats, including fake hotspots, Evil Twin attacks, and Man-in-the-Middle attacks.
  3. Analysed the risks associated with connecting to unknown public networks.
  4. Identified the target audience, including students, travellers, and everyday internet users.
  5. Studied existing safety practices and identified awareness gaps.
  6. Suggested solutions such as suspicious network identification, simple risk indicators, security warnings, and awareness tips.
Evidence
  • Project report documenting research and problem analysis.
  • Project presentation.
  • Research findings on public Wi-Fi security threats.
Learning
Through this project, I learned about public Wi-Fi security risks, fake hotspots, Evil Twin attacks, and Man-in-the-Middle attacks. I also improved my research, problem-solving, teamwork, documentation, and communication skills.
